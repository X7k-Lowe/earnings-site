AIで作ったものを公開する前に見る20項目

AIでWebページ、アプリ、販売ZIPを作ると、公開までの速度はかなり上がります。

ただ、速くなった分だけ、公開前に見落としやすいものも増えます。

  • .env やAPIキーを含めていないか
  • 有料ZIPを無料公開フォルダへ置いていないか
  • スクリーンショットに個人情報や管理画面が映っていないか
  • rm -rf や git push -f のような危険操作を確認なしで使っていないか
  • AIが書いた機能説明が、実物とずれていないか

このあたりは、才能よりも「毎回見る項目が決まっているか」で差が出ます。

無料で使える公開前チェックリストを置きました。

無料チェックリスト: https://x7k-lowe.github.io/earnings-site/tools/ai-release-checklist.html

使い方

公開直前にブラウザで開き、20項目を上からチェックします。

未確認が残ったら、その場で直します。全部終わったら結果をコピーして、公開ログやREADMEの末尾に残します。

有料版で増えるもの

AI個人開発 公開事故防止スターターパックには、無料チェックリストに加えて以下を入れています。

  • 公開前チェックリストのMarkdown版
  • 危険パターンCSV
  • Git pre-commit安全フック
  • コマンド確認用ガードスクリプト
  • AGENTS.md安全方針テンプレート
  • リリースチェックリスト
  • 公開後ログCSV

個別レビューや設定代行ではなく、自分の作業環境で繰り返し使うための材料です。
